# 🌐 VPN Subscription Hub

Репозиторий с автоматически собранными и проверенными конфигами для VPN-клиентов (Happ, v2rayNG, NekoBox). 

## 🚀 Что внутри?
*   **Актуальные ключи:** VLESS, Shadowsocks, Hysteria2, VMess, Trojan.
*   **Только живое:** Все конфиги прогнаны через TCP-чекер (мертвые отсеяны).
*   **Готово к импорту:** Файлы имеют нужные заголовки для отображения лимитов и названий в клиентах.

## 📥 Как использовать?
1. Скопируй ссылку на сырой файл (Raw).
2. Вставь её в свой клиент как новую подписку.
3. Обновляй подписку по мере необходимости.
